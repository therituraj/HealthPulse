About the HealthPulse project

HealthPulse is a machine learning project that predicts diabetes and heart disease. It combines trained models, a Flask backend and a live dashboard in one web app.

  • Built ML models for diabetes and heart disease prediction using Python and Scikit-Learn.
  • Reached 82% accuracy for diabetes and 79% for heart disease on the test dataset.
  • Designed a Flask-based backend with MongoDB integration.
  • Deployed an interactive dashboard for real-time predictions.

Questions people ask before they start

Is HealthPulse a medical diagnosis?

No. It gives a risk estimate from a machine learning model. Only a doctor can diagnose a condition, so please discuss your result with one.

How accurate are the predictions?

On our test dataset the diabetes model reached 82% accuracy and the heart disease model reached 79%. Real-world results can differ for individuals.

What information do I need to enter?

Common clinical measurements such as age, blood pressure, glucose, cholesterol and BMI. Each form field explains what to enter.

Does it cost anything?

No. HealthPulse is free. You only need an account to save and view your results.
